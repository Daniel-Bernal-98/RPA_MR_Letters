# Correspondence Processing Module

## Standard Operating Procedure (SOP)

### Purpose

Provide standardized instructions for processing insurance correspondence using the Correspondence Processing Module.

### Scope

Applies to all personnel using the Correspondence Processing Module.

---

### Required Files
- Input Folder
- Output Folder

Procedure
- Open the application.
- Select the Correspondence tab.
- Select the Input Folder.
- Select the Output Folder.
- Click Start Processing.
- Review processing results.
- Review Multi-Patient documents.
- Review Miscellaneous documents.
- Review generated processing logs.

---

### Validation

Verify:

- Payer identification
- State identification
- Patient extraction
- DOS extraction
- Classification accuracy
- File naming consistency

---

### Classification Review

#### Single-Patient Documents

Verify:

- Correct payer
- Correct patient
- Correct DOS
- Correct state

#### Multi-Patient Documents

Verify:

- Multiple patients are present in the document
- Historical year classification is correct (when applicable)

#### Miscellaneous Documents

Verify:

- Document is not associated with a patient claim
- No valid DOS is present


#### Exception Handling

If a document is incorrectly classified:

- Verify payer detection.
- Verify patient extraction.
- Verify DOS extraction.
- Review processing logs.
- Escalate unsupported formats for review.

---

## Security

This application processes protected healthcare information and must be used according to company policies.

Documents must only be processed and stored in approved company locations.
