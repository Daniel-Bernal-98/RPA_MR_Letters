# MR Letters Automation
## Standard Operating Procedure (SOP)

### Purpose

Provide standardized instructions for processing Medical Records request letters.

### Scope

Applies to all personnel using MR Letters Automation.

### Required Files

- Assignment CSV
- Input Folder
- Output Folder

### Procedure

1. Open application.
2. Select payer tab.
3. Select Assignment CSV.
4. Select Input Folder.
5. Select Output Folder.
6. Click Start Processing.
7. Review processing results.
8. Review UNASSIGNED folder.
9. Review generated CSV log.

### Validation

Verify:

- Collector assignment
- File naming
- DOS extraction
- Output folders

### Exception Handling

If files appear in UNASSIGNED:

1. Verify patient exists in CSV.
2. Verify document quality.
3. Review processing logs.

### Security

This application processes protected healthcare information and must be used according to company policies.
